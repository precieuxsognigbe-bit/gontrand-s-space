# Gontrand's Space

Crée un site portfolio one-page (ou multi-sections avec navigation ancrée) pour un architecte d'intérieur haut de gamme nommé AGAVOU Gontrand, dont l'entreprise s'appelle Architecture by Gontrand.

Positionnement : Professionnel formé à l'ENSAD et à Penninghen (deux écoles de référence en architecture/design), spécialiste du sur-mesure, capable d'intervenir sur des projets résidentiels, commerciaux et de rénovation haut de gamme. Le site doit transmettre une impression de rigueur technique, d'élégance et de savoir-faire — jamais de tape-à-l'œil.

Direction visuelle : Design épuré, minimaliste, beaucoup d'espace blanc/négatif pour laisser respirer les visuels. Typographie soignée (une serif élégante pour les titres, une sans-serif discrète pour le texte courant). Palette neutre (blanc cassé, noir/anthracite, un accent beige ou doré discret). Les rendus/photos de projets doivent être le point focal absolu — grandes images, transitions douces, pas de distraction visuelle.

Structure des sections :                                                                                                                          Hero — rendu fort en fond, nom, accroche courte, CTA "Découvrir le portfolio"

Portfolio/Réalisations — grille de projets filtrable (résidentiel / commercial / rénovation), chaque projet cliquable vers une page ou modal détaillée

À propos — parcours (ENSAD, Penninghen), philosophie de travail, photo professionnelle

Services/Process — étapes de collaboration (prise de contact, esquisse, sur-mesure, réalisation)

Témoignages clients

Contact — formulaire simple + coordonnées, logo "AG" en signature

Copywriting : Ton premium, phrases courtes et sensorielles (lumière, matière, volume, sur-mesure). Éviter le jargon commercial générique ("meilleur", "n°1"). Préférer la sobriété factuelle qui inspire confiance.

Technique : Responsive, chargement rapide malgré les visuels lourds (lazy loading), animations subtiles au scroll (fade-in, pas d'effets criards).
